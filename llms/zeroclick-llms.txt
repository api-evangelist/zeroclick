# ZeroClick

> ZeroClick is the agent-first storefront and transaction layer that turns any API or offering into an agent-purchasable service, with x402 and MPP (Machine Payments Protocol) payment rails, a machine-readable storefront, agent identity, and per-transaction analytics. Sellers keep their existing upstream API and Stripe account; ZeroClick operates the agent-facing payment, identity, and proxy layer in front of it. Launched July 2026 by the People's Internet Experiment; raised $55M.

## How it works
- Agents call a hosted per-seller pay URL (e.g. https://acme.pay.zeroclick.io/v1/...) using MPP or x402.
- ZeroClick handles wallet identity, payment challenges, and signed proxying to the seller's upstream API.
- The seller's API verifies the ZeroClick HMAC signature, checks allowance, and returns the result.
- Payment settles to the seller's connected Stripe account while ZeroClick records usage.

## Core objects
- Seller: your company/product; gets a pay URL and signing secret.
- Service: one thing agents buy (LLM model, data API, workflow, feature).
- Meter: a billable measurement in a service (requests, output_tokens, etc.).
- Plan: how agents pay (pay-as-you-go, credit, subscription, subscription+usage).
- Price: amount attached to a meter within a plan.
